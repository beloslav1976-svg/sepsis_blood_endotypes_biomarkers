# Ion Torrent Processing Paragraph

Sequencing data were processed on an Ion Torrent(TM) Server using Torrent
Suite(TM) Software version 5.18.2 and the ampliSeqRNA plugin version 5.18.0.0
(Thermo Fisher Scientific, Waltham, MA, USA). Primary processing included base
calling, quality filtering, barcode demultiplexing, trimming of technical
sequences, read alignment, and gene-level quantification. Output files included
raw gene-level read counts (.bcmatrix), reads-per-million normalized expression
matrices (.rpm.bcmatrix), and barcode- and run-level quality-control summaries
(.bc_summary). Chip, sequencing run, barcode, and study-group metadata were
retained for downstream quality control, integration of count matrices, and
assessment of technical variability.
