# Manuscript Publication Policy

The working manuscript DOCX is intentionally excluded from this public
repository staging package.

The repository is intended to support the scientific article by providing:

- publication-facing R scripts;
- main and supplementary figures/tables;
- freeze records;
- provenance and audit files;
- release-readiness documentation.

The final peer-reviewed article should cite the released GitHub repository and
Zenodo DOI. The manuscript text itself should be distributed through the journal
publication route, not through this GitHub repository.
