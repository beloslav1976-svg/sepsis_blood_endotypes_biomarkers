- Created a public GitHub repository for the blood endotype and biomarker
  publication package.
- Added publication-facing R scripts from Scripts 135-168.
- Added main Table 1 and Figures 1-5 in publication formats.
- Added Supplementary Tables S1-S10 and Supplementary Figures S1-S8 in
  publication formats.
- Added frozen supplementary and main-package audit records from Scripts 167
  and 168.

- Replaced local provenance path prefixes in freeze records with portable
  `SEPSIS_PROJECT_DIR` placeholders.
- Added release-readiness, privacy-screening, R-script portability, and
  provenance documentation.

  [10.5281/zenodo.22228576](https://doi.org/10.5281/zenodo.22228576), with
